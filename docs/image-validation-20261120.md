# 사용자 최종 이미지 통합·실기 검증 — 2026-11-20

`Rlyeh-Image-Final-Codex-Handoff-20261120.zip`의 최종 PNG 19장을 개발 소스와 로컬 게임에 적용했다.
이전 이미지 19장 중 14장이 바뀌었고, 아포칼립스 진입 제목 5장은 이전과 같은 파일이다.
전달본의 PNG를 바이트 그대로 복사했으며 재생성·리사이즈·재압축·색공간/알파 편집은 하지 않았다.

## 통합과 보존

- 기존 카탈로그의 native Sprite 이름·범위·캔버스를 기준으로 대응했다.
  `theme_title`과 `theme_logo`는 `rogue:1`~`rogue:5`를 함께 확인했다.
- 실제 프로젝트 형식에 맞춰 PNG 내용 해시 경로와 카탈로그의 해시·바이트 수를 갱신했다.
  과거 리뷰 패키지의 해시나 추정 캐시 파일명은 사용하지 않았다.
- 기존 소스·설치 이미지 묶음을 먼저 백업한 뒤, 이전 카탈로그에서만 참조하던 한국어 PNG를 정리했다.
  현재 소스와 게임의 이미지 목록은 각각 PNG 19개와 카탈로그 1개다.
- 플러그인·Core·hdTrans DLL, 용어집·Master/UI 문장집·검수 시나리오 데이터는 그대로 유지했다.
  게임 원본 번들·Sprite·Texture는 수정하지 않았고 F2의 원본 참조 복원을 유지했다.
- 정상 런타임을 사용했다. 진단용 DLL·별도 표시층·원본 위의 추가 덮어쓰기 경로는 넣지 않았다.

## 파일 검사

- 전달 ZIP CRC와 `SHA256SUMS.txt`, manifest의 19개 PNG 해시·바이트 수 검사 통과.
- 19개 대상 이름/범위가 기존 카탈로그와 일치. 각 PNG의 RGBA 및 native 캔버스 크기 검사 통과.
- 선택 카드 5장의 알파가 추출 원본의 알파와 픽셀 단위로 일치함을 재확인.
- 승패 본문과 발광의 알파는 서로 동일하지 않다. 전달된 최종 쌍을 그대로 유지했다.
- 이미지 데이터 검사 20개 파일, CoreChecks 80개, Python 15개 통과.
- 설치한 19개 PNG는 전달본과, 설치 카탈로그는 개발 소스와 바이트 단위로 일치한다.

편성·장비를 바꾸거나 구매·소환·보상 수령을 하지 않았다. 보석 잔액은 검증 전후 같았다.
