# 아포칼립스 보상 안내 클래스 아이콘 겹침 수정

2026-11-20, `feat/local-images` 로컬 소스와 설치 게임 검증 기록.

## 원인

테마 3·4·5의 보상 캐릭터 안내에 있는 금색 문양은 게임 원래의 클래스 아이콘이다.
번역 이미지나 폰트의 잘못된 글리프가 아니다.

`RogueThemeTopFrontDesignView` 프리팹은 `Message/Text`와 별도 `Message/IconImage`를 사용한다.
일본어 안내문은 캐릭터 이름 뒤의 ASCII 공백 세 칸에 아이콘을 고정 배치한다.
세 프리팹의 아이콘 위치가 일본어 이름 길이에 따라 각각 다르며, 이 위치를 재계산하는
네이티브 뷰 로직은 없다.

기존 검수 번역은 그 공백을 제거했다. 공백만 복원한 실험에서도 한글과 일본어의 실제
글자 폭 차이 때문에 테트라 이름 끝과 아이콘이 겹쳤다. 이전 이미지 적용 검증은 이미지
19개 자체의 대응을 확인했지만, 이 별도 UI 아이콘과 문장의 겹침을 놓쳤다.

## 수정

- 테트라·디시아·루오셴 안내 번역에 원래의 아이콘용 공백 세 칸을 복원했다.
- 기존 `UiReadability.Apply`에서 해당 네이티브 뷰와 형제 `IconImage`를 확인한다.
  TMP의 실제 렌더링 결과에서 보상 줄의 공백 중앙을 구해 아이콘의 가로 위치만 맞춘다.
- 세로 위치·크기·스프라이트는 네이티브 값을 유지한다. 번역문을 쓰는 별도 처리 경로,
  문자열 setter 후킹, 전역 스캔, 화면 좌표나 캐릭터명 하드코딩을 추가하지 않았다.
- 최초 아이콘 위치를 보존하고 기존 F2 복원 처리에서 되돌린다.
  예상한 뷰·아이콘·공백 구조가 없거나 공백 후보가 여러 개면 배치 보정을 하지 않는다.

검수 데이터의 원문·증거와 다른 번역 항목을 유지했다. 4,032개 런타임 항목 중
안내문 세 개의 대상 공백과 검수 이력만 변경했다. 최종 이미지 19개는 변경하지 않았다.

## 검증

일반 배포 빌드의 DLL과 수정한 카탈로그를 설치하여 실제 게임에서 확인했다.

| 확인 | 결과 |
|---|---|
| 테마 3 테트라 | 기본 창·최대화 창에서 이름/아이콘/조사 겹침 없음 |
| 테마 4 디시아 | 기본 창·최대화 창에서 이름/아이콘/조사 겹침 없음 |
| 테마 5 루오셴 | 기본 창·최대화 창에서 이름/아이콘/조사 겹침 없음 |
| F2 OFF → ON | 세 테마 모두 일본어와 원래 아이콘 위치 복원 후 한국어 배치 재적용 |
| 창 최대화·복원 | 세 테마 모두 배치와 안내문 표시 유지 |
| 테마 화면 재진입 | 루오셴 화면을 나갔다가 다시 열어 보정 재적용 확인 |
| 기존 데이터/Core 검증 | Python 15개, CoreChecks 80개 통과 |
| 게임용 빌드 | 성공. NuGet 취약성 정보 조회의 기존 네트워크 경고 NU1900만 발생 |
| 설치 파일 일치 | 빌드 DLL·텍스트 카탈로그와 설치본 SHA-256 일치 |
| 이미지·엔진 보존 | 이미지 19개/카탈로그, Core DLL, hdTrans 0.9.5 유지 |

기본 창의 캡처 크기는 1026×567, 최대화 창은 1536×824이다.
이번 변경에 관련된 화면과 F2를 실기 검증했으며, 시나리오·전투 등 전체 실기 회귀를
새로 순회한 것은 아니다. 전투·재화 사용·보상 수령은 하지 않았다.

텍스트 카탈로그 변경으로 캐시 버전도 변경됐다. 이전 캐시를 보존하고 이전의 원문
1,162개를 현재 동봉 hdTrans로 재처리했다. 실패 없이 완료했으며, 이전 번역 값을
새 버전 캐시에 복사하지 않았다. 게임에서도 준비된 캐시 1,162개와 hdTrans 0.9.5를 확인했다.

검증한 플러그인 SHA-256:
`c1f36444bbfb0a684eb0a6ee6948b1cd193c48eb988ac2df9631b39556eb2d1a`

텍스트 카탈로그 SHA-256:
`75c5e4c2ff23c0c147f7ad69f5c5b1cbc086f3f2d91dc8c31052920df421dbd8`

로컬 증거는 작업 공간의 `evidence/rogue-class-icon-20261120`에 보존했다.
원본 프리팹 좌표, 공백만 복원한 실패 실험, 세 테마의 한국어/일본어/창 크기 비교,
재진입 화면, 파일 검증 JSON과 실행 로그를 포함한다.
검증 후 게임을 종료하고 한국어화 ON 상태로 남겼다. 릴리스 파일 갱신이나 GitHub 게시는 하지 않았다.
