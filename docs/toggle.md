# F2 전체 ON/OFF

게임 창에서 F2를 누르면 한국어화 전체를 전환한다. 화면 오른쪽 위에 잠깐 현재 모드가 표시된다.
기존 화면은 화면 이동·재로딩 또는 다음 대사부터 반영될 수 있다.

| 모드 | 동작 |
|---|---|
| ON | 한국어 이미지, 검수 시나리오 행, Master·UI 검수본, 번역 캐시와 로컬 hdTrans 사용 |
| OFF | 원본 이미지와 일본어 행, native Master 반환값·UI 입력 사용. 새 번역 요청과 번역 결과 적용 중지 |

설정 파일의 `[General] Enabled`에 마지막 선택을 저장한다. 기본값은 true다.
OFF 상태로 게임을 다시 실행해도 F2로 ON할 수 있다. `[Images] Enabled`, `[Scenarios] Enabled`,
`[Local] TranslateUi`를 별도로 꺼둔 경우에는 해당 개별 설정을 존중한다.

## 원문과 기존 화면

- 이미지는 보관한 원본 Sprite/Texture 참조로 복원한다. 번들·공유 텍스처는 변경하지 않는다.
- 시나리오는 원문 Text 셀을 보존한다. OFF의 다음 대사 명령 실행 전에 원문을 복원한다.
- Master 레코드와 `GetText`/`GetDiffText`의 원래 반환값은 수정하지 않는다. 게임의 장기 보관
  `ActiveSkillModel`·`SpecialSkillModel`·`PassiveSkillModel.Text`에도 일본어가 남는다.
  검수 템플릿을 native 매개변수로 완성한 원문/번역 쌍은 별도 메모리에 등록하고 공통 UI 표시 경로에서 조회한다.
  OFF에서도 이 쌍을 준비할 수 있으므로 OFF로 로그인한 뒤 ON해도 검수본을 바로 사용한다.
  같은 원문에 상충하는 번역이 등록되면 해당 직접 매핑을 비활성화한다.
- 일반 TMP는 일본어 바인딩을 보존한다. 관찰한 컴포넌트의 처리 버퍼를 다시 만들며
  OFF 중 생성된 컴포넌트도 ON 전환에 대비해 기록한다. 일반 TMP setter 치환이나 주기적 TMP 탐색을 추가하지 않는다.
- UGUI와 전용 소환 확인 어댑터가 바꾼 문구는 동일한 컴포넌트·문맥·현재 값이 확인될 때만 원문으로 복원한다.
- 플러그인이 기록한 폰트와 가독성 설정도 복원한다. 현재 페이지에 이미 생성된 검수 TextData나
  과거 백로그를 강제로 다시 만들지는 않는다. 필요한 경우 화면 또는 스토리를 다시 연다.

입력란과 랭킹 사용자명 제외 정책은 그대로다. F2는 게임 진행, 스킵·자동 재생, 재화 사용을 조작하지 않는다.

## 캐시와 비동기 처리

각 번역 요청은 전체 스위치의 세대 번호를 가진다. OFF에서 새 요청·검수본/캐시 조회를 차단하고,
전환 전 요청의 결과는 이후 다시 ON하더라도 표시하지 않는다. 대기 작업도 worker에서 건너뛴다.
이미 실행 중이던 로컬 작업은 끝날 수 있지만 이전 세대의 화면에는 적용되지 않는다.
각 텍스트의 RevisionSlot 검사도 유지한다.

캐시와 사전을 지우거나 hdTrans를 다시 초기화하지 않는다. 엔진과 캐시는 준비된 상태로 유지하므로
ON 후에도 기존 캐시를 바로 사용할 수 있다. BepInEx와 호환성 런타임을 언로드하는 기능은 아니다.
외부 번역 API·CDN은 추가하지 않았다.
