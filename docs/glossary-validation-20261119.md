## 비교 범위

629개 일반 시나리오 book, Text 39,921행에서 **고유 본문 38,028개**를 비교했다.
화자 606개, 관련 Master/UI 원문 102개, 충돌·유지·용어 확인 문구 57개를 더해 총 **38,793개**다.
동봉 hdTrans 0.9.5 DLL과 같은 사전 스냅샷을 사용했으며, DLL·스냅샷을 갱신하지 않았다.

이 대량 비교는 제어 태그를 제거한 어휘 효과 검사다. UI 102개는 엔진에서 비교한 원문이며,
실제 UI에서는 검수 문장집이나 Master 표시 캐시가 먼저 적용될 수 있다.
`深きもの` 단독 정확 일치 등 실제 우선순위와 태그 처리는 별도 TranslationService 검사로 확인했다.
다른 이름 형식의 시나리오 11,142행은 이 비교 범위에 포함하지 않았다.
시나리오 전체를 수기 완역하거나 모든 book을 게임에서 재생했다는 의미는 아니다.

최종 차이는 본문 322개, 화자 121개, 엔진에 직접 넣은 Master/UI 원문 84개다.
일반 단어·용어 확인 문구의 변화 5개는 신님·대학·계승자·하인·고양이 장군의 의도한 적용이다.
본문 37,706개는 이전 결과와 같았고, 등록한 원문과 무관한 본문 변화는 0개였다.
숫자의 예기치 않은 변화도 0개다. 화자 `四将`의 `4장` → `네 장수`는 의도한 의미 수정이다.
대량 비교 뒤 마지막 긴 지명 2행과 유지 문구 57개를 다시 검사해 그 두 본문만 수정됨을 확인했다.

원문 전체, 후보별 문맥, 변경 전후 출력과 탈락한 시험 사전은 비공개 작업 증거에 보관한다.
canonical에는 근거 행 ID·해시·검수 이유·범위를 남겼다. 새로운 C# 이름 하드코딩이나 번역 엔진 규칙은 없다.

## 더 넓히지 않은 이유

- `深きもの` 전역 userdict: 종족 용례는 좋아지지만 `意味の深きもの`까지
  `의미의 심해인`으로 바뀌었다. 완전 일치하는 단독 입력만 허용했다.
- `アリス` 전역 names: 아리스노리스의 약칭은 통일되지만
  `이상한 나라의 앨리스`와 `거울의 나라의 앨리스`까지 아리스로 바뀐다. 전역 별칭은 보류했다.
- `雨飲みの傘`: 명칭은 자연스러워지지만 `傘をさす`가 `우산을 찌른다`로 바뀌었다.
  이름 목록 처리도 `우산을 가리킨다`와 사물에 대한 `에게`를 만들어 두 방식 모두 제외했다.
- `カミサマ`를 인명 목록으로 옮기는 시험: 일부 조사는 좋아지지만
  `신님이라고 대답`이 `신님과 대답`으로 나빠져 userdict를 유지했다.
  실제 인물의 별칭 `にゃー様`는 관련 문구·유지 문구를 별도로 비교해 이름 목록을 채택했다.
- `ミスカトニック`: 단독 시험에서는 잘못 읽혔지만 실제 대학명 문장들은 이미 미스캐토닉으로
  번역됐다. 효과 없는 중복 등록은 하지 않았다.
- `イス`는 실제 용례에서 의자이고, `ティア`는 노티아의 말더듬·이름 일부다.
  `フリーニ`·`ウルム` 등도 전체 이름의 일부를 독립된 새 이름으로 오인하지 않았다.
- ASCII `アフーム=ザー`의 의성어 오독은 names/userdict만으로 해결되지 않았다.
  `ザー` 전역 치환이나 엔진 수정으로 범위를 늘리지 않았다.

남은 후보는 이미 정상인 단어, 일반 어휘·의성어, 근거가 약한 별칭이나 표기 선호,
hdTrans의 문장 분석 문제 비중이 높다. 추가 전역 등록으로 얻는 작은 표기 이득보다
문맥·연어를 훼손하는 비용이 커지는 지점으로 판단해 이번 확장을 마쳤다.
새 이벤트에서 근거가 충분한 고유명사나 실제 오역이 발견되면 해당 항목부터 다시 검수할 수 있다.

## 검사와 설치

CoreChecks 80개, Python 15개를 통과했다. 기존 실제 서비스 fixture 136개와
신규 fixture 178개도 동봉 엔진으로 검사해 통과했다. 새 fixture는 정확 일치 범위, 본문 용어,
일반 단어 충돌 방지와 size/speed/ruby/interval/color 제어 보존을 포함한다.
태그가 한글 단어 사이에 위치할 수 있으므로 표시 문자는 태그를 제외하고 비교하고,
제어 스트림과 숫자는 원래대로인지 별도로 검사한다. 런타임의 태그 위치 정책은 바꾸지 않았다.

설치는 내보낸 다섯 파일을 함께 적용한다. 기존 캐시의 원문 요청 **1120개**를
새 사전으로 다시 처리했으며 오류·원문 유지 fallback은 0개였다.
이전 번역값을 새 revision으로 복사하지 않았고 기존 캐시는 보존했다.
준비된 현재 캐시는 1119개로 게임이 읽었다. 검수 문장집의 즉시 응답은 파일 캐시 행과 구분된다.

실제 게임의 0장 2화 전편에서 첫 대사와 아라타·네온의 화자명, 긴 본문의 끝까지 표시,
장면 이동 후 `꿈의 저택` 적용을 확인했다. F2 OFF는 해당 행의 일본어 원문을 복원했고,
ON 뒤 다음 페이지에서 한국어 화자·본문이 다시 적용됐다. 현재 행의 즉시 재번역을 요구하지 않는
전환 정책을 유지한다. 스킵 확인창과 회상 메뉴 복귀도 정상이다.
타이틀 로고와 홈 진입 로딩 소개 이미지의 기존 한국어 치환도 유지됐다.
해당 실행 로그에는 예외·엔진 실패·Master 표시 충돌이 없었다.
검증 시작·종료 재화는 같았고 구매·소환·육성·전투를 실행하지 않았다.
대표 화면의 확인이며 전체 629개 시나리오에 대한 native 실기 완료를 뜻하지 않는다.
검증 뒤 게임을 종료하고 한국어 ON으로 남겼다.
